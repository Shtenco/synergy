## Finance and economic truth gates

1. **Financial OS:** separate internal ledger balances, external cash, reserves, receivables, liabilities, mark-to-market values and realized settlement. Every state transition needs immutable event evidence and reconciliation.
2. **Payment System:** demonstrate idempotent payment creation, authenticated callbacks, duplicate/replay handling, refund/chargeback states, provider settlement reconciliation and failure recovery. API contracts do not prove actual settlement.
3. **USDS:** current central security register identifies a tracked deployer-key file in main and an open security PR that does not remove it from the PR branch. External rotation/revocation is unverified. Treat as compromised until independently evidenced; deployment and federation promotion remain blocked.
4. **No monetary overclaim:** token price, modeled TVL, accounting mark and actual liquid reserve are separate quantities. Do not count the same reserve across treasury, AMM and payment layers.
