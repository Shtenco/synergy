## Interpretation and limits

- A repeated HEAD means multiple branch names currently point to the same commit within one repository. It is a cleanup/review signal, not automatic permission to delete a branch.
- The 0/1,294 protection result is the live GitHub branch-list API field. Repository rulesets and organization policies require a separate policy audit.
- Ancestry comparison is a separate operation. The companion live comparison ledger contains 15 fresh comparisons so far; 1,187 non-main refs remain explicitly pending in that ledger. No un-compared branch is labeled merge-ready.
- A branch SHA is a content identity, not a quality verdict. Decisions require PR state, commit ancestry, CI evidence, issue references, release/tag use, and dependency checks.
