## Agent-system findings and acceptance gates

### NEXUS collective / OLGA

The previously identified source-level concern remains a release gate: a message-carried Ed25519 public key proves possession/consistency against that supplied key, not that the key is enrolled for the claimed `node_id`. Quorum must count distinct authorized node identities, not raw verified proposals. Required evidence: key registry binding, revocation, duplicate-node rejection, replay protection, quorum tests with Byzantine/Sybil cases and signed membership snapshots.

### AGI/NEXUS

The repository's branch and PR volume indicates active architectural iteration, not necessarily a running distributed agent. Require explicit runtime topology, process health, service-to-service authenticated calls, durable state, bounded permissions and end-to-end task receipts before operational classification.

### AGI Autopilot

Separate design/bootstrap/preproduction work from a deployed autonomous executor. The prior main README explicitly labels the baseline as a stub/architecture node. Preserve that maturity boundary until a reproducible build, admitted node identity, policy-enforced tool execution, kill switch, audit log and independent deployment evidence exist.
