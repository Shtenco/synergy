3. **Matrix kernels:** compare against stable BLAS/reference implementations; test numerical error, edge cases, precision, determinism, memory layout and performance on named hardware.
4. **Federation:** expose stable compute capability descriptors, not speculative throughput claims. A service consumer must verify device/runtime capability at admission.
