## Research integrity gates

1. **AI language/model branches:** record dataset source and license, preprocessing, split boundaries, training config, seeds, model artifact digest, inference environment, baseline comparison, calibration, leakage controls and independent rerun. A checkpoint file or notebook is not a reproducible model result by itself.
2. **Binary/quantum theory branches:** every claim must have an epistemic type. Distinguish source text, measured data, derived mathematics, numerical simulation, hypothesis and falsification. Record exact original datasets; do not substitute synthetic data for unavailable original measurements.
3. **Branch governance:** high branch count is not a maturity metric. Several branches may be snapshots or duplicate HEADs; branch cleanup requires merge-base, PR, tag, workflow and cross-repository reference analysis.
4. **No automatic integration:** keep research repos independent; integrate only stable, versioned contracts and artifacts with provenance.
